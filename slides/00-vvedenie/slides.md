# О чём этот курс

Коротко: это курс про **Python**, доведённый до уровня, на котором можно
собирать реальные сервисы — с веб-API, контейнерами, нейросетями и
языковыми моделями.

Формально предмет называется «Разработка кроссплатформенных приложений».
На следующем слайде — почему это название всё ещё имеет смысл, хотя мы
не пишем ни одной строчки под iOS или Android.

# Причём тут «кроссплатформенность»

10–15 лет назад это означало: один код — под Windows, macOS, Linux,
позже — под iOS и Android. Сегодня для большинства сервисов эта задача
решается иначе.

<v-clicks>

- Сервис живёт как **контейнер** с HTTP-интерфейсом
- Он не привязан к операционной системе клиента
- Достучаться до него может браузер, мобильное приложение, скрипт — или Telegram-бот
- «Кроссплатформенность» переехала с уровня клиентского кода на уровень архитектуры

</v-clicks>

# Как это выглядит в итоге

Результат курса — один Docker Compose-проект с двумя рабочими эндпоинтами:

- `POST /predict` — классификация изображения обученной моделью
- `POST /ask` — ответ на вопрос по базе документов (RAG)

Проверить их можно через `curl` или Swagger UI. Обернуть то же API в
Telegram-бота — отдельное задание со звёздочкой для тех, кто хочет пойти дальше.

# Чего не будет

<v-clicks>
